# General Knowledge-Junior

A student-friendly learning and quiz project for learners in Classes 4–10.

## Subjects
- [ICT](ICT/README.md)
- [Geography](Geography/README.md)
- [Science](Science/README.md)
- [Mathematics](Mathematics/README.md)
- [English](English/README.md)
- [History](History/README.md)

## Learning approach
- Clear, age-appropriate language
- Four options per multiple-choice question
- Correct answer and a short explanation
- Gradual difficulty suitable for Classes 4–10
- Questions reviewed for accuracy and ambiguity

## Question ID conventions
Geography: `GEO001`, `GEO002`, ...
ICT: `ICT001`, ...
Science: `SCI001`, ...
Mathematics: `MAT001`, ...
English: `ENG001`, ...
History: `HIS001`, ...

Each quiz should state its recommended class range and topic.
